# Atom Parfums — демо Telegram Mini App

Презентаційний прототип каталогу парфумерії на розпив (атомайзери 2, 5 і 10 мл). Без бекенду, оплати й надсилання замовлень.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статична збірка в dist/
```

## Відкриття в Telegram

Mini App вимагає HTTPS. Задеплойте `dist/` на будь-який статичний хостинг (Vercel, Netlify, GitHub Pages)
або прокиньте локальний сервер через тунель (наприклад, `cloudflared tunnel --url http://localhost:5173`),
потім у @BotFather: `/newapp` або «Bot Settings → Menu Button» і вкажіть URL.

## Структура

- `src/data/` — типи, словники, демо-каталог (`products.ts`: реальні аромати, об'єми розпиву `DECANT_SIZES`;
  замінити на реальний каталог/API).
- `src/store/` — стан застосунку (вкладки, обране, кошик, фільтри) і логіка фільтрації.
- `src/lib/telegram.ts` — адаптер Telegram Web App: `ready/expand`, safe area, висота в'юпорта,
  колір шапки, системна кнопка «Назад», тактильний відгук.
- `src/components/BottleArt.tsx` — векторні ілюстрації флаконів (тимчасово замість фото;
  додайте `image: '/products/xxx.webp'` у товар, і буде показано фото).
- `src/screens/` — Головна, Каталог, Обране, Кошик.
- `src/lib/motion.ts` + `src/motion.css` — система руху (характер «Premium»): переходи екранів
  через View Transitions, переліт флакона з картки в шторку, «стос» під шторкою, поява маскою
  під час прокручування, FLIP-перестроювання сітки, 3D-нахил карток, «живий» флакон, лічильники,
  що прокручуються, політ товару в кошик. `styles.css` містить лише статичну верстку.
- `public/logo.png`, `public/emblem.png` — логотип із `Logo.png` (обрізані поля, зменшено для вебу).

## Режим анімації

Якщо в системі ввімкнено «зменшити рух» (у Windows — вимкнені «Ефекти анімації»), застосунок
показує лише м'які проявлення прозорістю. Щоб показати повну анімацію на такому комп'ютері,
відкрийте демо з параметром `?motion=full` (наприклад, `http://localhost:5173/?motion=full`);
`?motion=system` повертає системну поведінку.

## Тимчасові рішення

- Аромати й піраміди нот реальні, а ціни розпиву, наявність та ілюстрації флаконів — демонстраційні.
- Обране й кошик зберігаються в `localStorage` браузера.
- «Оформити замовлення» лише показує повідомлення про демо-режим.
